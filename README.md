# School Safety Tactics 2D

Небольшой прототип 2D-игры на HTML5 Canvas про **безопасность в школе**.

## Что реализовано

- 3 режима:
  - Кампания на 20 уровней
  - Оборона
  - Песочница
- 2 локации:
  - Российская школа
  - Американская школа
- 6 персонажей (по 2 на роль):
  - Стрелок
  - Школьник
  - Полицейский
- HUD со счётом, уровнем, временем и спасёнными целями
- Управление: `WASD` / стрелки

## Запуск

Открой `index.html` в браузере.
